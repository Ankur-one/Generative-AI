# 🚀 Ank-One

## Enterprise AI Translator

Ank-One is a multilingual Generative AI Translation System built using:

- Python
- PyTorch
- Hugging Face Transformers
- FastAPI
- Streamlit
- SQLite
- Docker

## Features

- 🌍 200+ Language Translation
- 📄 PDF Translation
- 🖼 Image Translation (OCR)
- 🎤 Speech Translation
- 🤖 AI Powered Translation
- 📊 Translation History
- 🔐 User Authentication
- ☁ Cloud Deployment
